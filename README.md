# Studio Huntter Creators — Grupo VIP

Página de captura do Grupo VIP do Studio Huntter Creators.

## Arquivos

- `index.html` — a página completa (a foto já vai embutida)
- `icons/` — ícone da aba do navegador

## Onde mudar as coisas

No final do `index.html`, no bloco `// Configure aqui`:

- `GRUPO` — link do grupo do WhatsApp
- `VAGAS` — porcentagem da barra de vagas preenchidas

## Publicar no GitHub Pages

1. Em **Settings → Pages**, em **Branch**, escolha `main` e a pasta `/ (root)`, depois **Save**.
2. Em 1 a 2 minutos a página fica no ar em:
   https://fabiohuntter2.github.io/grupo-vip-huntterok/
3. Para usar seu domínio: em **Settings → Pages → Custom domain**, digite o domínio e siga as instruções de DNS.
